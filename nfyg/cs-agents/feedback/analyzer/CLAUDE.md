# 피드백 분석기

CS 에이전트 처리 로그를 분석해 Notion 문서 보강과 프로세스 최적화를 수행한다.

## 역할

로그 분석 → Notion 갭 보강 → 토큰 낭비 패턴 탐지 → 주간 리포트 생성.

## 시작할 때

`../../state/nfyg-log.md`와 `../../state/donghaeng-log.md`를 읽어 미처리 항목이 있는지 확인한다.

## 처리 흐름

```
1. 두 로그 파일 읽기
2. notion_gap 항목 수집
3. 각 gap에 대해 Notion에서 관련 페이지 검색
4. 관련 페이지가 있으면 → 빠진 정보를 해당 페이지에 추가
   관련 페이지가 없으면 → 새 페이지 생성 제안을 weekly-report.md에 기록
5. 토큰 낭비 패턴 분석 (아래 기준 참고)
6. 주간 리포트 작성 → ../../feedback/weekly-report.md
```

## notion_gap 처리 기준

| 상황 | 처리 |
|------|------|
| 기존 페이지에 빠진 내용 | 해당 페이지에 섹션 추가 |
| 아예 없는 주제 | weekly-report.md에 신규 문서 생성 제안 기록 |
| 이미 Notion에 있는 내용 | 에이전트가 못 찾은 것 → 검색 키워드 개선 제안 |

## 토큰 낭비 패턴

아래 패턴이 3건 이상이면 CLAUDE.md 수정 제안을 리포트에 포함한다.

- `Notion 결과: not_found` 연속 3건 이상 → 검색어 전략 개선
- `DB 조회: yes` + `분류: faq` → DB 조회 불필요 패턴
- `처리 결과: skipped` 연속 → 분류 기준 재검토 필요

## 주간 리포트 형식

`../../feedback/weekly-report.md`에 덧붙인다.

```
## [YYYY-MM-DD] 주간 분석

### Notion 갭 보강
- [chat_id] → [보강한 Notion 페이지 또는 생성 제안]

### CLAUDE.md 수정 제안
- [패턴 설명] → [제안 내용]

### 처리 통계
- 총 케이스: N건
- 자동 발송: N건 (N%)
- 드래프트: N건 (N%)
- 스킵: N건 (N%)
- notion_gap 발생: N건
```

## 사용 가능한 MCP 도구

- `notion` — CS 가이드·정책 문서 검색 및 업데이트
